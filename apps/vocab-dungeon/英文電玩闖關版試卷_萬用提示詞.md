# 英文電玩闖關版試卷｜萬用提示詞

## 使用方式

將下方「提示詞開始」至「提示詞結束」的內容複製到新的對話中，並在提示詞後提供英文單字資料。最簡單的格式是每行一組「英文, 中文意思」；也可以加入例句，格式為「英文, 中文意思, 例句」。系統應將新單字自動轉成題庫，不需要使用者逐題重新編排。

建議輸入格式：

```text
borrow, 借入
protect, 保護, We should protect our planet.
responsible, 負責任的
```

## == 提示詞開始 ==

請製作一份繁體中文介面的 **英文電玩闖關版線上試卷**。這是一份給國中學生自我複習英文單字用的互動測驗。請將我在本次訊息提供的英文單字自動加入題庫；如果沒有提供中文意思，請先列出缺少的資料並暫停出題，不要自行捏造教材答案。

### 一、題庫資料規則

1. 每一行視為一個單字資料，優先解析為：

   ```text
   英文單字, 中文意思, 可選例句
   ```

2. 英文單字應去除前後空白並以小寫形式保存；中文意思與例句保留原意。
3. 若同一個英文單字再次提供，應更新原本的中文意思或例句，不要重複建立相同題目。
4. 所有新單字都要自動加入兩個關卡：第一關「英文 → 中文」；第二關「聽音 → 英文拼字」。
5. 不要把沒有出現在使用者資料中的單字當成正式考題。若需要製作干擾選項，只能從本次題庫或既有題庫中選取，並且不可重複正確答案。

### 二、兩關遊戲流程

#### 第一關：英文 → 中文

每題顯示英文單字與「聽發音」按鈕，並提供四個中文選項。四個選項每次載入、重新開始或重新挑戰時都要隨機排列；畫面重新標示 A、B、C、D，但正確答案判定必須依選項文字，不得依賴答案位置。

#### 第二關：聽音 → 英文拼字

每題顯示中文意思。學生先按「先聽發音」播放英文單字，再於輸入框自行輸入英文拼字。送出時忽略前後空白與大小寫差異；空白輸入不得提交。支援按 Enter 送出，答題後顯示正確英文、學生答案與簡短拼字解析。

### 三、語音功能

1. 英文單字旁提供喇叭按鈕，可播放、重播與顯示「播放中」狀態。
2. 使用瀏覽器內建語音播放功能即可，不要依賴外部音檔；語系設定為 `en-US`，語速約 0.82。
3. 全域靜音按鈕必須同時控制戰鬥音效與單字語音。
4. 切換題目、關卡或結算時，停止上一題尚未完成的語音。
5. 若瀏覽器不支援語音功能，仍要保留文字輸入與測驗流程，不得讓頁面崩潰。

### 四、遊戲化介面

請採用像素地下城／Neo-Brutalist Pixel RPG 風格，具備：

- 固定 HUD：XP、擊敗數、總題數、COMBO、計時器、題庫工具與靜音按鈕。
- 每一題是一隻怪物；答對顯示命中、怪物 HP 歸零、綠色回饋與 COMBO 累加；答錯顯示反擊、紅色震動、COMBO 歸零，並列入優先複習。
- 第一關完成後顯示 checkpoint 過場，再進入第二關。
- 全部完成後顯示總 XP、擊敗數、最高連擊、作答時間、稱號與「再挑戰一次」。
- 所有主要操作按鈕要支援鍵盤焦點、Enter 操作與手機觸控。
- 主要行動色使用 Dungeon Coral `#FF6B57`；分數使用 Electric Yellow `#FFD166`；正確使用 Mint `#5DE2B3`；錯誤使用 Berry Red。

### 五、題庫工具與自動加題

頁面提供「題庫工具」面板，讓使用者可以直接貼上新的單字資料。按下「加入題庫」後：

1. 解析每行資料。
2. 驗證英文與中文意思均存在。
3. 合併新單字並避免重複。
4. 將題庫保存到瀏覽器本機儲存空間。
5. 新單字立即可出現在下一次完整闖關與複習闖關中。
6. 顯示成功加入幾個單字、目前題庫總數與格式錯誤提醒。

### 六、艾賓浩斯遺忘曲線複習紀錄

請將以下內容作為**簡化的間隔複習模型**，用於自我複習排序，不要宣稱它能精確預測個人的記憶，也不要將它當成醫療或心理診斷工具。

每個單字至少保存以下資料：

```js
{
  attempts: 0,
  correct: 0,
  wrong: 0,
  streak: 0,
  lastAnsweredAt: null
}
```

每次作答後立即更新：

- `attempts`：總答題次數加一。
- `correct` 或 `wrong`：依本次答案加一。
- `streak`：答對連續次數加一；答錯歸零。
- `lastAnsweredAt`：保存最近一次作答時間。
- `accuracy`：以 `correct / attempts` 計算顯示用正確率。

以連續答對次數決定下一次複習間隔：

| 連續答對次數 | 建議間隔 |
|---:|---:|
| 0 或尚未作答 | 今天 |
| 1 | 1 天 |
| 2 | 2 天 |
| 3 | 4 天 |
| 4 | 7 天 |
| 5 | 14 天 |
| 6 次以上 | 30 天 |

若單字答錯，應立即標記為「今日優先複習」。若目前時間已經超過 `lastAnsweredAt + 建議間隔`，也要列入今日複習。複習清單優先排序如下：

1. 已逾期且曾答錯的單字。
2. 尚未作答的單字。
3. 已逾期的單字。
4. 正確率較低的單字。
5. 最近尚未複習的單字。

頁面應顯示「今日複習 N 個」按鈕。按下後建立複習闖關，只抽出今日需要複習的單字；如果清單為空，顯示「目前沒有逾期單字，可進行全部單字闖關」。

### 七、資料保存與隱私

若未指定帳號或資料庫，預設使用瀏覽器 `localStorage` 保存題庫與學習紀錄，並清楚告知使用者資料只保存在目前瀏覽器。不得假裝資料已同步到雲端。若未來需要跨裝置、教師查看或多人共用，請另外提出登入與資料庫方案。

### 八、答案與隨機化

- 第一關選項必須在題目建立時隨機排列。
- 題目順序與選項順序都要在重新整理及再挑戰時重新洗牌。
- 答案判定必須以資料欄位的實際文字或正規化後的輸入比對。
- 每題答題後立即鎖定作答，顯示正確答案、學生答案、解題觀念與本單字目前的答題紀錄。
- 不得因選項位置改變而改變正確答案。

### 九、交付與驗證

完成後請提供可直接使用的線上測驗，並驗證：

1. 貼上新單字後能加入題庫。
2. 重新整理後自訂單字仍存在。
3. 第一關選項順序會變動，但答案判定正確。
4. 第二關可以播放發音並輸入英文拼字。
5. 答題次數、正確率、答錯次數與最近作答時間會更新。
6. 今日複習清單會依逾期與答錯狀態產生。
7. 全部答對時分數等於滿分，兩關流程能正常完成。
8. 手機與桌面版都能操作，且沒有 JavaScript 或 TypeScript 錯誤。

如果單字資料格式不完整，請先明確說明缺少哪些欄位，再繼續處理可辨識的資料；不要自行編造教材內容。

## == 提示詞結束 ==

## 補充說明

本提示詞把「遺忘曲線」轉成可在前端執行的簡化間隔複習規則。它適合做為國中英文單字的練習排序依據；實際學習效果仍會受到單字難度、學習時間、作答專注度與學生個人記憶差異影響。
