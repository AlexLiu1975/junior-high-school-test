# 康軒國二英文單字闖關測驗｜設計提案

## 三種風格方向

### 方向一：像素地下城
**Theme Name**：像素地下城

**Very Brief Intro**：以 16-bit RPG 地城為視覺語言，將每個單字題化為守關怪物。色彩鮮明、節奏快速，讓學生產生「再打一關」的複習動機。

**Probability**：0.073

### 方向二：學院任務板
**Theme Name**：學院任務板

**Very Brief Intro**：把測驗設計成校園冒險社的任務公告，採用紙張、貼紙、螢光筆與任務章的混合風格。氣氛親切而有成就感，降低考試壓力。

**Probability**：0.041

### 方向三：星際指揮艙
**Theme Name**：星際指揮艙

**Very Brief Intro**：以深色太空儀表板呈現單字挑戰，進度條是航線、連擊是能量核心、每題是待摧毀的太空目標。沉浸感強，適合強調分數與連續挑戰。

**Probability**：0.086

## 已選方向：像素地下城

### Design Movement
採用 **Neo-Brutalist Pixel RPG**：以像素遊戲的高對比幾何、厚重邊框與錯位陰影為主體，加入現代網頁的清晰資訊層級與響應式排版。

### Core Principles
1. **每題都像一個可視化挑戰**：題幹、選項與怪物狀態必須形成清楚的作答節奏。
2. **高對比但不刺眼**：深墨藍底搭配珊瑚橘、電光黃與薄荷綠，讓正確、錯誤、進度與分數有明確語意。
3. **遊戲回饋即時而短促**：回饋動畫控制在 100–300ms，不能阻礙學生繼續作答。
4. **內容優先、裝飾服務理解**：像素裝飾只放在 HUD、關卡標記與空間轉場，不遮蔽英文單字與解析。

### Color Philosophy
深墨藍代表專注的地城背景；珊瑚橘是主要行動色，讓「出擊」具有能量；電光黃專門標示分數與寶藏；薄荷綠代表答對與通關；莓紅代表怪物反擊。這套色彩不是單純裝飾，而是讓學生不讀長篇文字也能快速理解狀態。

### Layout Paradigm
採用「左側關卡路線＋右側戰鬥場」的偏心結構。桌面版左欄顯示關卡、連擊與作答節奏，右側以大幅題目卡承載主要內容；手機版則將關卡路線改為頂端水平 HUD，題目卡維持單欄，確保拇指操作。

### Signature Elements
- 像素風「地城入口」徽章與怪物血條。
- 厚重深色邊框配合向右下錯位的硬陰影。
- 答對時浮出的 `+XP`、COMBO 徽章與短暫綠色閃光。

### Interaction Philosophy
每次點選都要讓學生感受到「我已經造成影響」。選項 hover 會輕微上移，按下時縮小，送出答案後立即鎖定選項並呈現怪物受擊或反擊狀態。任何聲音都提供靜音切換，鍵盤也能完成作答。

### Animation
初始畫面以 30–60ms 的階梯式淡入呈現 HUD 與戰鬥卡。答對時使用短暫的 scale、opacity 與 translateY 組合，粒子從命中位置向外散開；答錯時只使用 160ms 左右的水平震動與紅色閃光。結算畫面使用一次性的彩帶與徽章升級動畫，並尊重 `prefers-reduced-motion`。

### Typography System
標題使用 `Bungee`，帶出街機與關卡感；正文使用 `Nunito Sans`，確保英文單字、中文解析與行動裝置閱讀清楚。標題採大寫或短句，正文維持 16–18px，題目單字以 32–48px 粗體突出；數字 HUD 使用等寬字體風格並提高字距。

### Brand Essence
**定位**：給國中生使用的康軒英文單字戰鬥場，用短回合、即時回饋與錯題解析，把背單字變成可以重玩的闖關任務。

**Personality**：俐落、鼓舞、帶點頑皮。

### Brand Voice
標題、按鈕與提示使用短促、有動作感的句子，避免空泛的「歡迎使用」。

- 「準備出擊：今天要擊敗哪一區單字？」
- 「命中！把這個單字收進你的 XP 背包。」

### Wordmark & Logo
標誌是一個沒有文字的像素盾牌：盾牌中央嵌入一本打開的字典，字典上方有一顆四角星，象徵「單字防禦力」與通關成就。網站標題旁使用此盾牌，favicon 也使用相同圖形。

### Signature Brand Color
**Dungeon Coral `#FF6B57`**：以珊瑚橘作為可辨識的出擊色，搭配墨藍背景時具有鮮明而溫暖的辨識度。

## 內容與功能規格

本版本先內建一組適合國二英文複習的示範單字題庫，題目採「看英文選中文」與「看中文選英文」混合出題。每次載入與重新挑戰時，單題順序會重新洗牌，但選項順序固定，避免解析對應混亂。每題都會在作答後顯示正確答案與簡短解題觀念；全部完成後顯示分數、擊敗數、最高 COMBO、耗時與稱號。

音效使用 Web Audio API 即時合成，不依賴外部音檔；介面提供靜音按鈕。資料先以前端常數維護，後續可再依指定冊次、課次或使用者提供的單字表擴充。
